# giovannitedesco.it

Sito di Giovanni Esteban Tedesco, astrofotografo di Brindisi.

Sito statico in un unico file (`index.html`) con le immagini in `img/`. Pubblicato con GitHub Pages sul dominio indicato in `CNAME`.

Per sostituire una foto con l'originale in alta risoluzione, carica il nuovo file in `img/` con lo stesso nome.
